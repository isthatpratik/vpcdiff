See what a Terraform plan opens to the internet.

vpcdiff reads a Terraform plan and shows every path the internet gains or loses, on AWS, Google Cloud, and Azure, with the rule and route that decide each hop. Free, open source, and offline.

Scan a plan · View on GitHub

How it works

  1. Make the plan: terraform plan -out=tfplan, then terraform show -json tfplan > plan.json.
  2. Run vpcdiff: the GitHub Action on every pull request, the CLI (run it with no arguments for a guided mode that finds or makes the plan), or the offline web viewer.
  3. Read the diff: one verdict for the plan (fix before merge, check by hand, review, or no new exposure), then every path from the internet, its answer before and after the plan, and the hop that changed.
  4. Gate the merge: the Action fails the check when the plan adds a path from the internet.
