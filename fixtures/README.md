# Fixtures

Each fixture folder contains:

- `after/main.tf`: the configuration under review.
- `before/main.tf` (optional): the configuration already applied. Without it, the plan creates everything.
- `plan.json`: generated by `pnpm fixture:plan fixtures/<name>`. Do not edit it by hand.
- `expected.json`: the expected engine result.
- `ORACLE.md`: how the expected result was verified.

`pnpm fixture:plan` needs Terraform, but not an AWS account. It plans `before/`, turns
that plan into a synthetic state (fake IDs, AWS example account `123456789012`), and
plans `after/` against it with `-refresh=false`. The output has a fixed timestamp, and
the fake provider credentials are removed, so regenerating gives the same file.

See [CONTRIBUTING.md](../CONTRIBUTING.md#fixtures) and [ADR 0004](../docs/adr/0004-reachability-analyzer-as-oracle.md).
